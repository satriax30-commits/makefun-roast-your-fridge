One roast line for a fridge door that only shuts with a hip-check, written to `/output/entry.txt` by a small deterministic Node 22 program (stdlib only, no network, no randomness). The line roasts the fridge itself — a $2,000 appliance that only works if you body-slam it first. Entry for the [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty on make.fun.

Run it with `node main.ts` (Node 22.18+), or `ENTRY_OUTPUT_DIR=<dir> node main.ts` to write the entry elsewhere for local testing.
